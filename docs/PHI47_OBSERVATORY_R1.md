# PHI47 Observatory R1 · Offline visual experiment

Open `phi47-observatory.html` in a modern browser or, after Pages deployment, visit `/phi47-observatory.html`. Run `node tests/phi47-observatory.mjs` using Node 20+.

This self-contained stage intentionally **does not** inject into the existing Atelier shader/decks, audio input, foldmesh storage or export pipelines. It visualizes a deterministic two-bubble, 47-pocket state machine with constant coarse observations and nine conditional interface teeth.

Controls: rotate the interface 0..46, open/close the synthetic boundary, compare Φ47 topology to two degree-eight alternatives, and export the 47-alignment sweep as JSON. There is no runtime import of actual NBG/Altermath receipts yet, no network requests, no user data, and no model execution.

The displayed interface correlation is a constructed binary-state statistic. It is not quantum coherence, physical energy, evidence of hidden dimensions, or demonstrated routing advantage.
